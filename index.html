Download the Windows kit ↓
03

Install, configure, launch

Open PowerShell in the extracted folder. Point the installer at your game folder, set your local server key, and start Flux Rec.

.\scripts\Install-FluxRec.ps1 -GamePath "D:\Games\RecRoomLegacy"

Then copy .env.example to .env, set a strong OPENREC_SECRET_KEY, and run Start-FluxRec.bat.

04GOOD TO KNOW

BEFORE YOU STEP IN

A few quick
answers.

Does the download include Rec Room?

No. Flux Rec only distributes project-owned source and tools. You need your own compatible game files from a source you are authorized to use. The download contains no game executable, assets, or third-party runtime binaries.

Is this an official Rec Room project?

No. Flux Rec is an independent community project and is not affiliated with or endorsed by Rec Room Inc.

Is this a ready-hosted online service?

The kit is designed for you to run a local Flux Rec server. This download does not include a centrally hosted world or promise that every original online feature is available.

What do I need on Windows?

Windows 10 or 11, a compatible local PC client with BepInEx initialized, Python 3.10 or newer, and the .NET 6 SDK. The installer builds and deploys the Flux Rec client tools against your local game files.
