# Flux Rec website

Static website for [fluxrec.sitey.my](https://fluxrec.sitey.my), published from this repository with GitHub Pages.

The Windows button downloads the project-owned `FluxRec-runtime.zip` from the `riporipoteam-ctrl/fluxrec` repository. It contains Flux Rec's setup scripts, local server, configuration templates, documentation, and compiled project DLLs. It does not contain the proprietary game client or third-party runtime binaries. A compatible game install and the tools listed on the site are still required.

## Files

- `index.html` — landing page and setup instructions
- `styles.css` — responsive visual system and motion
- `script.js` — small navigation, copy, and reveal interactions
- `assets/` — original Flux Rec mark and generated hero art
- `CNAME` — GitHub Pages custom domain

The site has no build step or external JavaScript dependencies. To preview locally, serve this directory with any static HTTP server.
